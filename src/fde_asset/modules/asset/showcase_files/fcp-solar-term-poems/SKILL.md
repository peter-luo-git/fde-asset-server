# 节气诗笺

让日常工作里多一点人文气息：周会开场、节日问候、项目里程碑，配一首应景的诗。

## 步骤

1. **定日期**：用户说了日期就用那天，没说就是今天（北京时间）。运行
   `python3 scripts/today.py [YYYY-MM-DD]`，拿到节气、节日和古诗原文（JSON）。
   - `solar_term`：所处节气；`is_term_day` 为真表示当天交节；`days_into_term`、`next_term`、`days_to_next_term`
   - `festival`：当天的传统节日（春节、元宵、端午、七夕、中元、中秋、重阳、腊八、除夕）；`festival_soon`：7 天内的节日
   - `poems`：相关古诗原文（节日的在前）
   - 只内置了 2024–2035 年；超出范围时如实告诉用户，不要自己推算节气日期
2. **讲时令**：两三句话说清这个节气或节日的物候、风俗，平实，不堆砌。
3. **引古诗**：从 `poems` 里选一两首，**原文照抄**，标明作者、朝代。
   - 不要凭记忆补诗句、改字；`poems` 里没有的诗，不要说成是原文
   - 原文里括号中的「一作……」是校勘注，诗笺上可以去掉，但不要换成别的字
4. **写新诗**：按 `references/格律.md` 写一首新诗，默认七言绝句，用户指定体裁就按用户的。
   - 意象要贴合当下：节气物候 + 用户给的场景（比如项目上线、团队周会、某人生日）
   - 写完对照格律自查字数、押韵、平仄；拿不准的地方在「创作说明」里如实说明，不要硬说完全合律
   - 新诗是原创，标「新作」，不要冒充古人作品
5. **排诗笺**：用户要图片或网页时，按 `templates/诗笺.html` 填好，存到工作目录（默认 `poems/<日期>-<节气>.html`），用浏览器打开即可截图分享。
   只要文字时，直接按下面的格式回复。

## 回复格式

```
【时令】2026年10月26日 · 霜降第 3 天（12 天后立冬）
……两三句物候和风俗……

【古诗】杜牧《山行》（唐）
远上寒山石径斜，白云生处有人家。
停车坐爱枫林晚，霜叶红于二月花。

【新作】七言绝句《题目》
……四句……

【创作说明】意象取自……；押……韵；第 x 句平仄为……（如有出律处如实说明）
```

## 不要做的

- 不要编造诗句、出处，或者把新作说成古人的
- 不要给节气、节日配迷信说法（宜忌、吉凶），只讲物候、风俗和诗
- 用户要的是团队问候时，语气温暖克制，不要过度煽情

## 来源

古诗原文取自 chinese-poetry 数据集，格律规则改编自 poetry-skills，许可见 `references/LICENSES.md`。
