## 用户当前要求优先

用户或任务明确要求的步骤、指定 Skill、只读范围，以及「不另写方案」「不等确认」等要求，优先于本示范流程。不得增加用户排除的方案、任务或其他产物；已有充分指令时直接执行已授权工作，不为示范流程另加等待确认。平台强制审批仍须遵守，Skill 本身不授予工具权限。

只读查询、冒烟检查和逐项回答按当前请求完成，不进入开发发布流程。用户指定的 Skill 先按其要求使用，不得先读取本示范的长流程或要求先经过本示范入口。

## 按需读取完整示范

本技能是可选的项目开发交付示范，只有用户实际要求使用这一完整流程，或任务已经明确选择该流程时，才读取 [完整流程正文](references/project-development-workflow.md)，再按当前授权范围采用所需步骤。一般需求讨论、设计、实施或恢复开发本身不触发本技能。

参考文件保留原完整流程，供选择本示范时查阅；其流程建议受上面的用户优先规则约束。不要因示范而自动安装或关联其他技能；所需技能未提供时如实说明，并继续可独立完成的已授权工作。来源收据、权限、版本、审批恢复和副作用幂等边界由平台校验；内容究竟属于用户要求还是 Agent 建议，仍须按真实来源核对，不能仅凭有收据就视为用户确认。
